# Domain and DNS Basics Reference

DNS, the domain name system, is the address book of the internet: it translates a domain name people can remember into the numeric addresses and routing information machines need. When you own a domain, DNS records are how you point it at a website, route its email, and prove ownership. The pieces that confuse people most are the record types, the difference between your registrar and your nameservers, and why changes take time to take effect.

This reference covers domain and DNS basics in plain language, for an indie operator setting up their own domain.
